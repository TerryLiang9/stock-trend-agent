# xuanling（玄铃）— A股智能分析系统 演示讲解稿

---

## 一句话定位

> 一个集成多数据源、多 AI 模型、多策略框架的 A 股智能分析平台，支持 Web 看板、AI 对话、定时任务、趋势预测和团队协作。

---

## 一、项目背景与解决的问题

做 A 股投资面临三个痛点：

1. **信息过载** — 每天面对海量行情、新闻、公告，人工筛选效率低
2. **分析碎片化** — 技术面、基本面、资金面、消息面各自独立，缺乏综合判断
3. **决策无追踪** — 看完就忘，没有系统化的信号记录和回测验证

xuanling 把这些能力整合到一个平台里：**自动取数据 → 多维度分析 → AI 综合判断 → 生成报告 → 推送通知 → 记录追踪**。

## 三、核心功能模块

### 3.1 多数据源自动切换

| 数据源 | 用途 | 优先级 |
|--------|------|--------|
| TickFlow | 实时行情 + 日线（WebSocket） | 高 |
| Efinance | 实时行情 + 日线 | 中 |
| AkShare（腾讯/新浪/东财） | 实时行情 + 基本面 | 中 |
| Tencent | 日线 K 线 | 低 |
| Tushare | 实时 + 日线 + 基本面（需 Token） | 可选 |
| Baostock / Pytdx | 历史日线 | 备选 |

每个数据源都有**熔断器**保护——连续失败 3 次自动跳过，5 分钟后重新尝试。一个源挂了自动切下一个，用户无感。

### 3.2 AI 多 Agent 分析引擎

不是简单的"问 GPT"，而是一个**多 Agent 协作系统**：

| 模式 | Agent 链路 | LLM 调用量 | 适用场景 |
|------|-----------|-----------|----------|
| `quick` | Technical → Decision | ~4-8 次 | 快速看盘 |
| `standard` | Technical → Intel → Decision | ~6-15 次 | 日常分析 |
| `full` | + Risk Agent | ~8-20 次 | 深度研报 |
| `specialist` | + 策略专项 Agent | ~15-40 次 | 多策略对比 |

每个 Agent 都是 **ReAct 循环**（思考 → 调工具 → 观察结果 → 再思考），最多 10 步。工具包括：

- 📊 行情数据：实时行情、日线历史、筹码分布
- 📈 技术分析：趋势判断、均线系统、量价分析
- 📰 情报检索：新闻搜索、公告抓取、研报摘要
- 💰 资金面：主力资金流向、板块排名
- 🏢 基本面：估值、成长性、机构评级

### 3.3 20 个内置交易策略

策略是 YAML 驱动的，可以热加载，不用改代码：

| 策略 | 说明 |
|------|------|
| `bull_trend` | 默认多头趋势（MA 多头排列 + 回踩低吸） |
| `shrink_pullback` | 缩量回踩（缩量回调 MA5/MA10 → 反弹买入） |
| `ma_golden_cross` | 均线金叉 |
| `volume_breakout` | 放量突破 |
| `bottom_volume` | 底部放量 |
| `trend_follow` | 趋势跟随 |
| `mean_reversion` | 均值回归 |
| `box_oscillation` | 箱体震荡 |
| `wave_theory` | 波浪理论 |
| `chan_theory` | 缠论 |
| `dragon_head` | 龙头战法 |
| `emotion_cycle` | 情绪周期 |
| `event_driven` | 事件驱动 |
| `expectation_repricing` | 预期重定价 |
| `growth_quality` | 成长质量 |
| `historical_analog` | 历史相似日 |
| `hot_theme` | 热门题材 |
| `one_yang_three_yin` | 一阳三阴 |
| `wavelet_trend` | 小波趋势 |
| `logistic_6factor` | 六因子逻辑回归 |

### 3.4 趋势预测（四模型融合）

专门针对"明天涨还是跌"的量化预测：

| 模型 | 方法 | 权重 |
|------|------|------|
| 均线基线 | MA 多头/空头排列 + 斜率 + 乖离率 | 70% |
| 小波趋势 | 小波变换去噪 → 趋势外推 | 10% |
| 历史相似日 | KNN 寻找历史上最相似的 K 线形态 | 10% |
| 六因子回归 | 逻辑回归（WVAD/OBV/CMF 等六因子） | 10% |

四模型加权打分，输出**五分类信号**：强多头 / 弱多头 / 多空拉锯 / 弱空头 / 强空头。

### 3.5 通知推送

支持 **8 种通知渠道**，分析完成后自动推送：

企业微信 · 飞书 · 钉钉 · Telegram · Discord · Slack · 邮件 · 自定义 Webhook

支持**定时推送**（如每日 18:00 收盘后自动分析 + 通知）、**静默时段**设置。

## 五、运行方式

```bash
# 1. 定时批量分析
python main.py --schedule

# 2. 指定股票分析
python main.py --stocks 600519,688981

# 3. 大盘复盘
python main.py --market-review

# 4. 启动 Web 服务（API + 前端）
python main.py --serve-only
# 或双击 start_server.bat

# 5. 桌面应用
npm run tauri dev   # apps/dsa-desktop/
```

## 七、给老板讲的亮点（30 秒版本）

> 我们做了一个 A 股智能分析平台，叫 xuanling。
>
> **三个核心能力**：
> 1. **自动取数** — 接了 7 个行情数据源，一个挂了自动切下一个
> 2. **AI 分析** — 不是简单问 ChatGPT，而是一个多 Agent 协作系统，技术面、情报面、风控分头分析，最后综合决策，内嵌 20 个交易策略
> 3. **趋势预测** — 四个模型融合打分，判断明天涨跌方向，有回测验证
>
> 现在是 Web + 桌面双端，支持定时任务 + 多渠道通知，整个团队都能用。已经在公司内网部署了。
